
# EduInsight AI 🎓

**AI-Powered Education Feedback Analysis Platform**

EduInsight AI is a data analysis platform designed to explore and analyze educational feedback using Python and Artificial Intelligence techniques.

## Features
- Dataset exploration
- Data analysis and visualization
- Topic analysis
- Sentiment analysis
- Interactive Streamlit dashboard

## Technologies
- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-learn
- Streamlit

## Project Structure
- `app.py` — Streamlit application
- `data/` — Dataset files
- `models/` — Machine learning models
- `notebooks/` — Data analysis notebooks
- `results/` — Analysis results

## Run Locally

```bash
pip install -r requirements.txt
streamlit run app.py
```
